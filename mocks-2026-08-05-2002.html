⚠ SCOPE: this file is the LANDING PAGE ONLY. It does not replace mocks-2026-07-27-1830.html, which is the app-screen gallery (70 phone frames: signup, roster, student detail, log screen, celebrate, menus). That file is still the reference for app screens and is still two releases behind — the Jul 30 navigation pass and all of Aug 1 are missing from it. Nothing here fixes that.
This is a real capture, not a hand-drawn replica. The markup below is the server-rendered HTML of /, and the styles are the page's own stylesheet plus globals.css, both inlined verbatim. Scripts are stripped, so it opens standalone with no server and no network. The landing page uses zero images — every device mock is inline SVG and CSS — so unlike the older mocks-*.html files this one has no asset dependencies at all.

⚠ It is therefore fully responsive and live: resize the window and you get the real breakpoints, not a fixed frame. Standard checks used all day were 375 / 414 / 768 / 1024 / 1280 / 1440.

What changed on 5 Aug 2026

  • Removed entirely: the old “Here’s how it works” section — four phone frames, then briefly numbered steps, then deleted. Section 2 and the new student section cover it between them at full size.
  • Added: section 3 (student-facing, two screens: log screen + student home) and the pricing section (two cards, shared feature checklist).
  • Colour system: sections 2 and 3 locked into one desaturated blue family.
  • Eyebrow: “For instructors” → “For coaches & trainers”, now matching the page metadata.
  • CTAs: all four bumped 17px → 19px/700 to cross the WCAG large-text threshold, so white-on-brand-blue at 3.59:1 passes against a 3.0 requirement instead of failing 4.5. ⚠ Load-bearing — below 18.66px or under weight 700 they fail again.

Known, deliberate, and recorded in CLAUDE.md

  • ⚠ Nothing on this page has ever been visually confirmed. The browser pane never painted during the session that built it, so every value was verified by measurement (getBoundingClientRect / getComputedStyle) rather than by eye. This capture is the first chance to actually look at it.
  • The rigid band-to-band seams are a known problem and the next planned pass (gradients / bleed). The pricing checklist dropping straight into the footer is the same issue at the final seam.
